# Halo

> 必要な操作を、必要な瞬間に、カーソルの周りへ召喚する。

Halo は macOS 用のラジアルランチャーです。グローバルショートカットを押すと、
カーソルの位置を中心に円形のメニューが現れます。方向にマウスを弾いてキーを離すだけで、
アプリの起動・URL のオープン・ショートカット実行・シェルスクリプト・クリップボード操作が走ります。

Swift / SwiftUI / AppKit のネイティブアプリで、外部依存はありません。

---

## デザイン

Halo の見た目は円グラフ（パイ）ではありません。

- **細い光のリング**の円周上に、独立した**ノード**が浮かびます。扇形の区切りは使いません。
- 選択は、リング上を走る**発光アーク**と**コメット**、そして中心から伸びる**フィラメント**で示されます。
- サブリングに潜っても親リングは消えず、内側へ縮んで**エコーリング**として残ります。
  いま自分がどの階層にいるかが、常に同心円として読み取れます。
- 主光源は温かいゴールド、その残響が寒色のバイオレット。

**召喚のモーション**もフェードインではありません。リングの線がカーソルの周りを一周しながら
描かれ、その中心から光の波紋が広がり、ノードが順番に中心から所定の位置へ飛び出します。
全体はカーソルを軸に少し回りながら定位置に収まります。閉じるときは待たされないよう、
遅延なしで一気に消えます。速度は外観設定の「アニメーション速度」に従い、
システムの「視差効果を減らす」を有効にしている場合はすべて単純なフェードになります。

## 機能

| | |
|---|---|
| **召喚** | グローバルホットキー（既定は <kbd>⌥</kbd><kbd>Space</kbd>）／修飾キーのダブルタップ／マウスボタン／メニューバー |
| **選択** | カーソルを方向へ動かす／<kbd>←</kbd><kbd>→</kbd>／スクロール／<kbd>1</kbd>〜<kbd>9</kbd>／**文字を打って絞り込み** |
| **実行** | キーを離す／クリック／<kbd>Return</kbd> |
| **サブリングへ** | リングの外側へ押し出す／クリック |
| **親リングへ戻る** | 中心へ引き戻して静止／<kbd>Tab</kbd>／右クリック |
| **キャンセル** | <kbd>Esc</kbd>／中心でクリック |

### アクションの種類

- **アプリ起動** — パスまたは Bundle ID。ノードには実際のアプリアイコンが出ます
- **アイコン** — SF Symbol は設定の「選ぶ…」から検索付きのピッカーで選べます
- **URL を開く** — `https://google.com/search?q={clipboard}` のようにプレースホルダが使えます
- **ショートカット実行** — インストール済みショートカットを一覧から選択。クリップボードを入力に渡せます
- **シェルスクリプト** — `/bin/zsh -lc` で実行。出力をクリップボード／ペースト／通知へ流せます
- **クリップボード** — コピー／ペースト／プレーンテキストペースト／消去／**履歴リング**
- **システム** — 画面ロック、ディスプレイスリープ、範囲／ウインドウのスクリーンショット、ダークモード切替、Mission Control、デスクトップ表示、音量±／消音、最前面アプリを終了、他のアプリを隠す、新規 Finder ウインドウ、ゴミ箱を空にする、アプリ切替リング
- **サブリング** — 別のリングを開く。**動的リング**（クリップボード履歴・起動中アプリ）も指定可
- **AI** — Apple のオンデバイスモデル。既定では無効。有効化すると `{input}` を含むプロンプトを実行し、結果をクリップボード／ペースト／HUD へ

### 押しっぱなし と タップ

- キーを**押したまま**方向へ動かして離す → その場で実行（スプリングロード方式）
- キーを**素早く押して離す** → リングが開いたまま残り、クリックで選べます

しきい値は設定で変更できます（既定 0.28 秒）。

### カスタマイズ

設定 > 外観で、リングの見た目と挙動をひと通り変えられます。プリセットも 4 種類あります。

| 項目 | 内容 |
|---|---|
| 寸法 | リング半径 90〜360pt、ノード 32〜120pt、リングの太さ、文字サイズ、デッドゾーン、潜る距離 |
| 配置 | 開始角度（0〜360°）、広がり（60〜360° = 扇形配置）、時計回り / 反時計回り |
| 形 | ノードの形（円 / 角丸 / 六角形 / ダイヤ）、中心の表示（カプセル / 文字のみ / 非表示）、項目名の位置（外側 / 内側 / 選択中のみ / 非表示）、アイコン（原色 / モノクロ）、番号バッジ |
| 光と色 | アクセント、セカンダリ、発光の強さ、選択アーク・コメット・中心線の表示切替 |
| 背景 | なし / 全体を暗く / リング周りだけ暗く / 背景をぼかす、＋強さ |
| 挙動 | 押しっぱなし判定、戻る静止時間、アニメーション速度、外へ押し出して潜る、中心へ引き戻して戻る、スクロール回転、数字キー、触覚フィードバック |

**広がり**を 360° 未満にすると扇形に並びます。開始角度と組み合わせると、画面の端で呼び出すときに便利です。

### 召喚方法

| 方法 | 権限 | 備考 |
|---|---|---|
| グローバルホットキー | 不要 | 既定 <kbd>⌥</kbd><kbd>Space</kbd>。設定で録音し直せます |
| リング専用ホットキー | 不要 | リングごとに割り当て。コンテキストを無視して直接開きます |
| 修飾キーのダブルタップ | アクセシビリティ | 左右の ⌘⌥⌃⇧ と fn を個別に指定できます |
| マウス／トラックパッドのボタン | アクセシビリティ | 中クリックやボタン 4・5 |
| メニューバー | 不要 | 「Halo を呼び出す」 |

どの方法でも「押している間だけ表示 → 離して実行」と「素早く押して離す → 開いたまま」の
両方が同じように働きます。イベントは横取りしない（listenOnly）ので、中クリックなどは
元のアプリでの動作もそのまま残ります。

### 絞り込み

リングが出ている状態で文字を打つと、項目名で絞り込めます。中心に検索アイコンと入力中の
文字が表示され、残った項目だけがリングに並び直します。クリップボード履歴や起動中アプリの
ように項目が多いリングで効きます。

<kbd>delete</kbd> で 1 文字消し、<kbd>esc</kbd> でまず絞り込みを解除、もう一度でリングを閉じます。
数字キーの直接実行は、絞り込みが空のときだけ働きます（数字も検索できるようにするため）。

絞り込みで項目が消えても選択は迷子になりません。選んでいた項目が残っていればそれを追い、
消えたときだけ近い位置へ寄せます。

### AI

Apple のオンデバイスモデル（`FoundationModels`）を使います。**API キーもアカウントも不要で、
入力したテキストがこの Mac の外に出ることはありません。** ネットワークには接続しません。

既定の AI リング:

| 項目 | 入力 | 出力 |
|---|---|---|
| 日本語に / 英語に | 選択テキスト | その場に置き換え |
| 要約 | 選択テキスト | クリップボード |
| 整える / 丁寧に | 選択テキスト | その場に置き換え |
| コードを説明 | 選択テキスト | HUD |
| 自由入力 | リングで打った文字 | クリップボード |

**リングがそのままプロンプト入力欄になります。** AI リングを開いて文章を打つと、名前で
一致しない項目は消えますが「自由入力」だけは残って選択されます。そのまま実行すれば、
打った文章がプロンプトとして渡ります。

#### 結果の確認

生成結果は**確認パネル**に出ます。いきなり文書が書き換わることはありません。

- 元のテキストと結果が並び、結果は**その場で編集できます**
- 「選択範囲を置き換える」で、元の選択範囲に適用（<kbd>↩</kbd>）
- 「コピー」「もう一度」「閉じる」（<kbd>esc</kbd>）
- 生成中はテキストが流れ、「中止」で止められます

置き換えを提案するのは、元の文を書き直す項目（翻訳・整える・丁寧に）だけです。
要約やコード説明は元の文を消さないので、コピーが既定になります。

確認を挟まず即適用したい場合は、設定 > AI の「適用する前に結果を確認する」を
オフにできます（既定はオン）。

必要条件は macOS 26 と Apple Intelligence が有効であること。使えない場合は設定 > AI が
理由と対処を表示します。

### 選択テキストの取得

「選択テキスト」を入力に指定した項目は、2 段構えで読み取ります。

1. アクセシビリティ API の `kAXSelectedText`（副作用なし）
2. 取れなければ ⌘C を合成し、`changeCount` を監視して取得後に**クリップボードを元に戻す**

ブラウザや Electron 製アプリの多くは選択を AX で公開しないため、2 が実質必須です。
復元は文字列だけでなく元の全表現（装飾付きテキストや画像）を保存して書き戻します。

### 実行前の確認

取り消せない操作（ゴミ箱を空にする、最前面のアプリを終了）は、既定で確認ダイアログが出ます。
項目編集の「実行前に確認する」で、どのアクションにも同じ保護をかけられます。

### 通知

スクリプトの失敗や実行結果は、画面上部の HUD で知らせます。macOS の通知は使いません
（許可されていない環境では失敗が黙って握りつぶされるため）。権限は不要で、必ず表示されます。

### リング専用ホットキー

リング一覧で「専用キー」にチェックを入れると、そのリングを直接開くキーを割り当てられます。
ルートリングやコンテキストのルールを飛ばして、いつでも同じリングが出ます。
ほかのアプリが使用中のキーは登録に失敗するので、その場で警告が出ます。

### Context Ring

呼び出した瞬間に最前面だったアプリを見て、開くリングを切り替えます。
Safari なら「URL をコピー / リーダー / 新規タブ」、Xcode なら「ビルド / 実行 / 停止」といった具合です。
一致するルールがなければルートリングが開きます。設定 > コンテキストで自由に追加できます。

### プレースホルダ

URL・スクリプト・AI プロンプトで使えます。

```
{clipboard}  {selection}  {app}  {bundleID}  {date}  {home}
```

## ビルドと実行

```bash
./Scripts/build.sh release run
```

`build/Halo.app` が生成され、起動します。`/Applications` へコピーしても構いません。

デバッグビルドは `./Scripts/build.sh debug`、ビルドのみなら末尾の `run` を省きます。

### 開発用フラグ

```bash
# 2 秒後に自動でリングを召喚（スクリーンショット用）
open build/Halo.app --args --summon-after 2

# リングをオフスクリーンで PNG に描画して終了
.build/release/Halo --render-preview out.png --depth 2 --select 4

# 絞り込み中の状態と HUD を含めて描画
.build/release/Halo --render-preview out.png --filter "ス" --select 0 --hud

# オンボーディングの各ページを描画
.build/release/Halo --render-welcome out.png --step 1

# 特定のリングを描画
.build/release/Halo --render-preview out.png --ring halo.ai --filter "要約して"

# 確認パネルを描画
.build/release/Halo --render-ai-panel out.png

# オンデバイスモデルを実際に呼んで確認（プロバイダ層を通す）
.build/release/Halo --ai-test "次を日本語に翻訳してください。\n\nHello"

# 確認パネルを実際に表示
open build/Halo.app --args --ai-panel-demo
```

## 権限について

Halo は初回起動時に何も要求しません。必要になった機能だけが権限を求めます。

| 機能 | 必要な権限 |
|---|---|
| ホットキー召喚、アプリ起動、URL、スクリプト | **不要** |
| リング内の絞り込み、実行結果の HUD | **不要** |
| AI（オンデバイス） | **不要**（macOS 26 + Apple Intelligence） |
| ペースト（⌘V の合成）、選択テキストの取得 | アクセシビリティ |
| AppleScript を使う項目（Safari の URL 取得など） | オートメーション |

権限がない場合は静かに機能を落とし、リングが画面に残ることはありません。

## 設定ファイル

```
~/Library/Application Support/Halo/config.json
```

GUI（メニューバー > 設定）で編集できますが、JSON を直接書いても構いません。
壊れた JSON は `config.broken-<timestamp>.json` として退避され、既定値で起動します。
古いバージョンで書かれた設定も読めます。知らないキーが増えていても既定値で補完するので、
アップデートでリングが失われることはありません。

API キーは **config.json に保存されません**。Keychain か同名の環境変数から読み込みます。
クリップボード履歴もメモリ上のみで、ディスクには書き出しません。
パスワードマネージャなどが機密指定（`org.nspasteboard.ConcealedType`）したコピーは記録しません。

### AI を拡張する

`AIProvider` に準拠した型を作り、`AIService.register(_:)` に渡すだけです。
リング項目、実行経路、設定 UI はすべて配線済みなので、追加はプロバイダ 1 つで済みます。
`stream` は既定実装があるので、一括応答しかできないプロバイダでも `complete` だけで動きます。

```swift
struct MyProvider: AIProvider {
    let identifier = "my-provider"
    let displayName = "My Provider"
    func readiness() -> AIReadiness { .ready }
    func complete(prompt: String, config: AIConfig) async throws -> String { … }
}
```

`AIConfig.knownProviders` に識別子を足すと、設定ファイルの検証にも載ります。

## 初回起動のガイド

初回だけ 3 ページのガイドが開きます。メニューバーの「使い方を見る」でいつでも再表示できます。

1. **Halo とは** — マークがその場で描かれ、ハイライトがリングを回り続けます
2. **ジェスチャ** — ミニチュアの Halo が召喚→狙う→実行を繰り返して**実演**します。
   文章で説明しづらい操作なので、動きそのものを見せています。「いま試してみる」で本物が出ます
3. **はじめの設定** — ログイン時起動、ショートカットの録音、権限の説明

ページはスワイプするように入れ替わり、各ページの要素は少しずつ遅れて立ち上がります。
ウインドウ自体もわずかに拡大しながらフェードインします。
「視差効果を減らす」設定時はアニメーションを行わず、実演も静止します。

## バックアップとリセット

設定 >「バックアップ / リセット」から操作します。

**書き出し** は 2 種類あります。「すべての設定」はそのまま復元するため、
「リングのみ」は専用ホットキーや AI 設定を含まないため、他の環境と共有できます。

**読み込み** は「すべて置き換える」か「リングを追加する」を選べます。追加のときは
ID を振り直したうえでサブリング参照を自分のコピーへ張り替えるので、既存のリングと
衝突しません。どちらの場合も、解決できないサブリング参照とコンテキストのルールは
自動的に外れます。読み込んだ設定が原因で「押しても何も起きないノード」は生まれません。

**リセット** は範囲を選べます。

| 範囲 | 消えるもの | 残るもの |
|---|---|---|
| 外観だけを初期化 | サイズ・色・配置・挙動 | リング、ショートカット |
| リングを既定に戻す | リングと項目、コンテキスト | 外観、ショートカット |
| ショートカットと召喚方法を初期化 | メイン／リング専用キー、修飾キー・マウス設定 | リング、外観 |
| コンテキストのルールを消去 | アプリ対応づけ | リング本体 |
| AI 設定を初期化 | プロバイダ・モデル・プロンプト | Keychain のキー |
| すべてを初期化 | すべて | — |

いずれも確認ダイアログが出ます。

## 既知の制限

- 3 本指スワイプのようなマルチタッチジェスチャでの召喚は未実装です（指の本数を取れる
  公開 API がないため）。ポインタ側は「マウス／トラックパッドのボタン」で代替できます。
- マルチディスプレイでは、カーソルのあるディスプレイにリングが出ます。
  画面端では、リング全体が収まる位置へ中心をずらし、カーソルもそこへ移動させます。
